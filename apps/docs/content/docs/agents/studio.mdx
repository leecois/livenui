title: Studio
description: Tune live effects, save presets and export portable configurations.
---

[Open Studio](/studio)

Studio opens a fullscreen workspace. Choose a component, starting example or saved preset in Components; interact with the live preview; then switch between Customize and Code in the inspector.

Customize includes advanced controls, Edit JSON, API reference and portable import/export. Code combines installation steps, your current React snippet and an agent prompt. Switching inspector tabs keeps the preview running.

Returning to a component restores its unsaved configuration during this Studio visit. Choose Save preset to keep a named configuration across reloads. Presets stay in this browser; export JSON for a portable copy. On smaller screens, Components opens as a drawer while preview and settings remain available.
