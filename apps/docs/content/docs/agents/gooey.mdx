## Try the interactions

Morph opens a staggered action menu. Move gives the slider a spring and trailing edge.
Bend lets you drag a project pill and release it back into place. Melt blends two draggable images.
Use the behavior selector beneath the preview to switch scenes; arrow keys also move the slider,
project pill and images. Escape resets the project pill, and Home resets an image.

The liquid silhouette draws the surface. Keep its content background transparent so the surface
can stretch and merge around crisp text and icons. The central action uses the shared accent gradient.
