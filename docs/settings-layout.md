# Settings layout

On guides, settings sit directly below the preview and before current integration code. Studio keeps Customize beside its persistent preview, with advanced search and JSON disclosure; saved presets occupy the Presets inspector tab. See [Studio workspace](studio-workspace.md). All views continue to use the same playground configuration owner.

## Reference and adaptation

The public [Eclipse customization panel](https://pro.reactbits.dev/docs/components/eclipse) was inspected in Chromium on 2026-10-06. It groups controls into a three-column grid with labels and values inside compact neutral rows, a nearby Reset action, numeric tracks and switches. The reference uses 32px numeric controls; Liven UI keeps its existing 44px native targets. No paid source, reference artwork or external palette is included.

The public [Blinds configuration](https://feralui.dev/blinds) was inspected in Chromium on 2026-10-07. It places joined categorical strips beside aligned labels and separates numeric dials into a three-column grid. Labels and values sit inside the filled drag boxes. Pressing a reference dial does not jump its value; horizontal movement adjusts it relative to the initial value, arrow keys step and double-click resets. There are no native selects in that panel. Its roughly 26px choice targets and 30px dials inform the anatomy only; Liven UI adapts joined strips and filled dials with 44px native targets, local tokens and its existing exact-edit contracts. Active dragging follows pointer position across the whole field so its edges match the minimum and maximum. Double-click complements the explicit Default action and omits the prop so the SDK resolves its default. The complete catalog review in [interface research](interface-research.md) extends this to direct chip grids and inline expansion for larger enums; settings no longer use dropdowns.

The public [student page](https://gemini.google/students/) was inspected in Chromium on 2026-10-07. Its section chooser separates targets within a neutral capsule and moves a dedicated rounded background with transform/width transitions. Liven UI applies this anatomy to radio, tab and device tracks with its own 4px inset/gaps, 44px targets, 12px radio text padding, accent fill and shorter 240ms motion. Reference branding, colors and assets are not imported.

Use the functional layout with local tokens: 20px panel insets, 12px field gaps, rounded-full neutral rows and bright gradient selection. Keep selected tabs/radio pills filled with `--gradient-accent` and white text. Checked switches use the same gradient with a white thumb. Accent contrast warnings remain accepted design trade-offs.

## Control contract

- Essential controls use one dense grid without category headings. Expanded Studio settings reveal Appearance, Motion and Interaction headings. Keep every field under the same grid parent with a stable key across expansion/collapse so invalid drafts survive. Sort the fields in DOM order to match the visual layout and keyboard navigation; advanced headings and dividers are grid items. Advanced search filters the same fields without creating another configuration store.
- Choice and switch rows place labels in a 112px column beside the value, with a 12px gap. Two- or three-option tracks use balanced equal cells. Larger enums place the heading above a two- or three-column chip grid. Below 550px, these labels move above with an 8px gap. Numeric, color and text labels stay inside 54px shells with 4px insets and a 1px border. Inset radio strips have 4px padding and gaps around 44px targets: the 1px border produces a 54px single-row strip; larger lists use a transparent grid instead of wrapping a capsule. Categorical controls precede the value grid, separated by a quiet divider when both kinds are present.
- Numeric dials combine a full-area neutral progress fill with an invisible native range covering the shell, an inline label, exact input and a 44px Default action. Show the numeric value once. The drag target includes the displayed value; only Default and a focused exact editor handle their own pointer input. Pressing does not jump. After 4px of horizontal movement, pointer position maps across the whole field to its minimum and maximum, including when starting over the displayed value. Clicking the value without dragging focuses its native editor; double-clicking the focused editor selects text. A pending valid exact draft is applied before the gesture starts. Dragging updates preview and code live; arrow keys step, Shift steps ten times, Home/End select the drag limits, and Escape, touch cancellation or lost capture restores the value before the gesture. Double-click omits the prop, matching Default.
- Hovering the range, focusing it with the keyboard or dragging reveals a decorative ruler. Minor ticks divide the field into tenths; major ticks mark fifths. The 4px upper inset keeps the 4px/8px ticks above the text. A 2px foreground marker uses the existing progress position, without a separate state owner; Auto, CSS lengths and values outside the drag window omit it. The rounded shell clips the ruler, and its entire layer uses `aria-hidden` and `pointer-events: none`. Reveal/hide uses the 160ms feedback token, snapping under reduced motion. Exact editing and the Default action retain their existing hit targets and focus cues.
- Curated presentation metadata in `lib/controls.ts` defines each numeric field's recommended drag window, step, unit and editing limits. These are not SDK API changes. Metal ring strength is bounded to 0–1; Text/Badge multiply strength by metal opacity and use a soft window. Image strength is bounded to 0–2. Speed can accept exact positive values outside its 0.25–3× drag window; custom values remain visible. The drag window stays visible below the inline label; the step and keyboard instructions are available in the tooltip and accessible hint. Focus adds no content or height. Numeric, color and text shells show one focus ring, with no nested input ring. JSON/import parsing retains existing runtime contracts and can preserve values outside the control's window.
- Exact numeric and color input uses a local draft. Enter or blur applies a valid value; Escape restores the last applied value. Invalid drafts show adjacent text and preserve preview/code. Empty input or Default omits the prop so the SDK resolves its own default; Auto never injects a guessed fallback. Replacement by Reset, import, saved configuration, starting point or component variant discards old field drafts, even when the replacement contains the same value. Editing a draft invalidates pending asynchronous imports.
- Color controls combine an inline 80px label column, 44px native picker target, swatch and flexible expression entry inside one shell. Text fields also use an inline 80px label column. Exact color/text inputs expose the complete value in a tooltip. CSS colors, variables and color-mix stay intact for CSS-rendered fields. Orb tint accepts its native hex/rgb formats; avatar tint also accepts hsl. A picker selection intentionally replaces the expression with a hex value.
- Avatar size presets ascend from 32px to 96px with decorative size markers, retain numbers and add Custom for an exact number or CSS length. The Beam `size` prop is labeled Style because its values also select line and pulse treatments; exported API names remain unchanged. Fabric fur fields appear only for Fabric; Voice dot/line fields follow the selected look. Hidden values remain in configuration and export.
- Keep visible labels associated with native controls. Radio fieldsets have an accessible legend and a visible heading. Larger enum grids use separate 44px rounded-full chips with 8px gaps, a transparent grid background, local hover/border feedback and one inset focus ring. Optional enum defaults omit the prop and show an explicit default status. Long labels wrap within their cell. No configuration dropdown is needed.
- Boolean settings remain native checkboxes with a 44px target and a decorative switch track. A quiet On/Off status indicates the effective value; Auto identifies an omitted prop. Both label clicks and Space toggle the same configuration. Focus is visible around the track.
- Typed choices remain native radio groups in Guide and Studio. Two or three options use inset neutral strips with equal cells and 12px horizontal text padding. SelectionTrack moves one decorative gradient indicator for 240ms; initialization, resize and zoom snap directly. Larger enums use chip grids without a travelling indicator. Show eight initially and retain a selected option outside that subset; inline expansion reveals every option. Starting examples show six. Preserve native arrow-key selection, custom values and numeric size types. Size presets plus Custom use a grid and keep exact numeric/CSS entry available.
- Keep Studio Customize / Presets / Code in a fixed inspector toolbar, outside the scrolling settings. Reset sits above the fields without repeating the Customize label. JSON uses a button disclosure; saved presets use their own inspector panel. Guides omit these administrative surfaces.
- Keep advanced discovery in the footer, separated by a quiet divider. Search only appears when advanced controls are expanded. Keep Saved input/action together and let JSON actions/help wrap at narrow widths. Validation feedback stays beside the panel.

Value columns follow the settings panel width: three at 900px or wider, two below 900px and one below 550px. Categorical rows use two columns at 900px or wider and one below; shape grids occupy a full row. See [design](../design.md) and [development](development.md).

## Avatar workspace

[Bot avatars](avatar-playground.md) place essential configuration beside the character on wide feature containers and below it on compact screens. Each controls panel queries its own width.
